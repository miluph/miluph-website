## One Framework, Two Specialized Codes

The **miluph** framework comprises two distinct Smoothed Particle Hydrodynamics (SPH) implementations tailored to your available hardware architecture:
<CardGrid>
  <Card title="miluphCUDA — Single-GPU" icon="laptop">
    Designed for maximum throughput on a single NVIDIA GPU. Ideal for rapid prototyping, parameter studies, and workstation-scale simulations without MPI overhead.
    </Card>
  <Card title="miluphHPC — Multi-GPU & Cluster" icon="server">
    Built with **MPI** for distributed, large-scale simulations across multiple GPUs and HPC compute nodes with dynamic domain decomposition.
  </Card>
</CardGrid>

## Core Capabilities

<CardGrid stagger>
  <Card title="Accurate SPH & Solid Physics" icon="starlight">
    Full continuum mechanics, elasto-plasticity, brittle fracture, self-gravity, and correction shemes for high numerical consistency.
  </Card>
  <Card title="miluph-studio" icon="setting">
    A browser-based GUI for configuring initial conditions, monitoring jobs, and managing remote HPC workflows on Slurm and SSH clusters.
  </Card>
  <Card title="Validated in Planetary Science" icon="magnifier">
    Actively used in planetary defense and astrophysics research, including impact modeling and validation for ESA's **Hera mission**.
  </Card>
  <Card title="Native CUDA Performance" icon="rocket">
    Written from the ground up in C/CUDA to exploit modern GPU memory hierarchies and massive thread parallelism.
  </Card>
</CardGrid>
